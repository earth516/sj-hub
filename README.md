# SJ SCIENCE 허브 (샘플)

과목 → 단원 → 활동(개념·탐구·문제·정리) 흐름으로 기존 사이트들을 한곳에 모으는 허브 사이트 샘플입니다.
학번 + 비밀번호로 로그인하고, 활동을 마칠 때마다 누른 **완료** 기록이 구글 시트에 저장됩니다.

## 파일 구성

```
sj_hub_sample/
├── index.html          ← 화면 (건드리지 않아도 됨)
├── config.js           ← 선생님이 고치는 곳: Apps Script 주소, 과목·단원·활동 목록
├── lessons/            ← 수업 페이지 내용 (단원 하나 = 파일 하나)
│   └── earth-1-2-1.js  ← 예시: 대기 대순환과 표층 해류
├── images/             ← 수업 페이지 그림 (폴더 이름은 영문으로)
├── apps-script/
│   └── Code.gs         ← 구글 시트에 붙여 넣을 서버 코드
└── README.md
```

## 1. 먼저 체험해 보기 (설정 없이)

`index.html`을 더블클릭해서 열면 **체험 모드**로 동작합니다.
학생은 `10101` / `1234`, 선생님은 `teacher` / `1234`로 로그인할 수 있고, 기록은 그 브라우저에만 저장됩니다.

## 2. 구글 시트와 연결하기

1. 새 구글 시트를 만듭니다. (기존 명단 시트를 써도 됩니다)
2. [확장 프로그램] → [Apps Script]를 열고, `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
3. 위쪽 함수 목록에서 `setup`을 고르고 [실행]을 누릅니다. 권한 허용 창이 뜨면 허용합니다.
   → 시트에 `학생명단`, `진도`, `기록` 탭과 내용 탭(`단원`, `OX`, `뉴스`, `헷갈린개념`)이 생깁니다. 내용 탭에는 예시 단원(대기 대순환과 표층 해류)이 채워져 있습니다.
   (`기록` 탭에는 학생이 쓴 질문과 생각이 쌓입니다.)
4. `학생명단` 탭에 학생을 채웁니다: **학번 | 이름 | 비밀번호 | 역할**
   - 선생님 줄(`teacher`)의 비밀번호를 꼭 바꿔 주세요. 역할 칸이 `교사`인 계정만 대시보드를 볼 수 있습니다.
   - 반은 학번(5자리)에서 자동으로 나눕니다. 10101 → 1학년 1반.
   (기존 문제은행 명단을 그대로 복사해 와도 됩니다. 예시로 들어간 10101 홍길동 줄은 지워 주세요.)
5. [배포] → [새 배포] → 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**
6. 배포 후 나오는 웹 앱 주소(`https://script.google.com/macros/s/…/exec`)를 복사해서
   `config.js` 맨 위 `const API_URL = '';` 따옴표 안에 붙여 넣습니다.

> Code.gs를 고친 뒤에는 [배포] → [배포 관리] → 연필 아이콘 → 버전: **새 버전**으로 다시 배포해야 반영됩니다.
> (주소는 그대로 유지됩니다)

## 3. 보안 원칙

- 비밀번호 확인은 구글 서버(Apps Script)에서만 합니다. 사이트 코드에는 명단·비밀번호가 없습니다.
- 로그인하면 **출입증(토큰)**을 받아서 씁니다. 브라우저에는 비밀번호를 저장하지 않습니다. 출입증은 6시간 뒤 만료됩니다.
- 비밀번호를 5번 틀리면 10분 동안 로그인이 막힙니다.
- 구글 시트는 공유하지 마세요. Apps Script가 선생님 권한으로 읽기 때문에 공개할 필요가 없습니다.
- 학생이 비밀번호를 잊으면 `학생명단` 탭에서 선생님이 직접 바꿔 주면 됩니다.

## 4. 단원·활동 추가하기

`config.js`의 `SUBJECTS`에서 단원 안의 `steps`에 한 줄을 넣으면 됩니다.

```js
{ type: 'lab', title: '심층 순환의 발생 원리 추론하기', url: LAB('earth-science/atmosphere-ocean/deep-circulation') },
```

- `type`: `video`(개념) · `lab`(탐구) · `quiz`(문제) · `note`(정리)
- `LAB('경로')`는 SJ SCIENCE LAB의 보고서 주소를 만들어 줍니다.
- 진도 기록은 "과목|단원코드|활동 제목"으로 저장되므로, 활동 제목을 바꾸면 새 활동으로 처리됩니다.

## 5. GitHub Pages에 올리기

`index.html`, `config.js` 두 파일만 저장소에 올리면 됩니다. (`apps-script` 폴더는 올리지 않아도 됩니다)

## 6. 점검 단원 내용 관리 (구글 시트)

연결한 뒤에는 **점검 단원의 내용을 시트에서 고칩니다.** 고치면 사이트에 바로 반영됩니다(학생 화면은 다음에 열 때).

| 탭 | 열 | 메모 |
|---|---|---|
| 단원 | 과목 · 대단원 · 단원코드 · 제목 · 목표 · 시간 · 그림 · 그림 설명 · 개념 요약 · 제시어 · 모범 정리 · 공개 | 과목은 `지구과학`/`통합과학`. 개념 요약은 한 칸 안에서 줄바꿈(Alt+Enter)으로 항목 구분, `**굵게**` 가능. 공개에 `X`를 쓰면 숨김 |
| OX | 단원코드 · 번호 · 문항 · 정답 · 해설 | 정답은 `O` 또는 `X` |
| 뉴스 | 단원코드 · 제목 · 출처 · 날짜 · 링크 · 요약 · 질문 · 설명 | 단원마다 여러 개 가능 |
| 헷갈린개념 | 단원코드 · 보기 | 한 줄에 보기 하나 |

- **그림**은 GitHub 저장소의 `images/` 폴더에 올리고, 시트에는 `earth-1-2-1/map.jpg`처럼 폴더 아래 경로만 적습니다. `https://`로 시작하는 주소도 됩니다.
- **단원코드**는 과목이 달라도 겹치지 않게 써 주세요.
- **OX 정답과 모범 정리는 사이트 코드에 들어가지 않습니다.** 채점은 서버(Apps Script)에서 하고, 모범 정리는 학생이 개념 정리를 저장한 뒤에만 보내 줍니다.
- 반영이 늦으면 시트 메뉴 **[SJ 대시보드] → [사이트 내용 바로 반영]**을 누르세요.
- 이미 연결해서 쓰던 시트라면 메뉴의 **[내용 탭 만들기 (처음 한 번)]**으로 내용 탭만 추가할 수 있습니다.

## 6-1. 예시 파일로 단원 만들기 (체험 모드)

`API_URL`이 비어 있는 체험 모드에서는 `lessons/` 폴더의 파일을 씁니다. 아래는 그 파일의 형식입니다.

단원에 `lesson: '파일 이름'`을 적으면 `lessons/파일 이름.js`의 내용으로 수업 페이지가 열립니다.

```js
{ code: '1-2-1', title: '대기 대순환과 표층 해류', lesson: 'earth-1-2-1' },
```

단원 점검은 단계(steps)로 나뉩니다. 기본 구성은 **개념 정리 → 세상과 연결 → OX 확인** 3단계(5분 안팎)입니다.

- 개념 정리 글을 저장하거나, 뉴스 설명을 열거나, OX를 끝까지 풀면 그 단계가 **자동으로 완료**됩니다.
- OX는 **처음 끝까지 푼 점수만** 기록됩니다. 다시 풀어도 기록은 바뀌지 않습니다.
- 학생은 상단 **📁 내 기록**에서 단원별 개념 정리와 OX 점수를 모아 볼 수 있습니다(포트폴리오).
  선생님은 시트 `기록` 탭에서 전체 학생 기록을 봅니다. (항목 `summary` = 개념 정리, `ox` = OX 점수)

필요하면 아래 단계 종류를 더 넣을 수도 있습니다.

| type | 화면 이름 | 하는 일 |
|---|---|---|
| observe | 👀 관찰 | 그림·자료를 보고 생각하기 |
| ask | ❓ 질문 | 내 질문 적기 |
| concept | 📖 개념 | 개념 설명 읽기 |
| explore | 🧪 탐구 | 자료 해석, 시뮬레이션, 실험 |
| news | 📰 세상과 연결 | 뉴스·실생활 사례 |
| check | ✅ 확인 | OX, 문제은행 |
| reflect | 🔁 돌아보기 | 처음 질문으로 돌아가기 |

### 수업 페이지 블록

각 단계의 `blocks`에 아래 블록을 위에서부터 차례로 넣습니다.

| 블록 | 예시 | 설명 |
|---|---|---|
| 소제목 | `{ h: '① 왜 바람이 불까?' }` | |
| 문단 | `{ p: '글 <b>강조</b>' }` | `<b>`로 굵게 |
| 그림 | `{ img: 'map.jpg', caption: '설명', width: 640 }` | 누르면 크게 보기 |
| 목록 | `{ list: ['첫째', '둘째'] }` | |
| 표 | `{ table: [['제목1','제목2'], ['내용','내용']] }` | 첫 줄이 제목 |
| 강조 상자 | `{ callout: '꼭 기억할 내용' }` | |
| 펼쳐 보기 | `{ more: '예시 보기', list: [...] }` | |
| 질문+답 | `{ qa: '질문', a: '답' }` | 답은 눌러야 보임 |
| 글쓰기 | `{ write: 'summary', label: '안내', hint: '제시어1, 제시어2', placeholder: '예시', model: '선생님 정리' }` | 시트 `기록` 탭에 저장. `model`을 넣으면 저장 뒤 선생님 정리가 열려 비교 |
| 헷갈린 개념 | `{ confuse: ['보기1', '보기2', '헷갈린 것 없음'] }` | 하나 고르기, 대시보드에 집계 |
| 내 글 보여 주기 | `{ showWrite: 'q1', label: '처음 질문' }` | 앞에서 쓴 글 |
| 짝 맞추기 | `{ match: { options, items, explain } }` | 예시 파일 참고 |
| OX | `{ ox: [{ q, a: true/false, exp }] }` | 바로 채점, 첫 점수 기록 |
| 뉴스 | `{ news: { title, source, date, url, summary, ask, answer } }` | |
| 링크 카드 | `{ links: [{ title, desc, url }] }` | url이 비면 "준비 중" |

## 7. 그림 자료 저작권

`images/` 폴더의 그림은 GitHub Pages에 올리면 **로그인과 상관없이 누구나 주소로 볼 수 있습니다.**
교과서 출판사 그림을 쓸 때는 출판사의 교사 자료 이용 범위(수업용 공개 게시 허용 여부)를 먼저 확인하세요.

## 8. 선생님 대시보드

선생님 계정으로 로그인하면 **📊 대시보드**가 열립니다. 단원과 반을 고르면 다음을 볼 수 있습니다.

- **개념 정리 모아 읽기 · 채점**: 반 전체의 개념 정리, OX 점수, 처음 제출·마지막 수정 시각. 학생마다 **점수(0~5)와 한 줄 코멘트**를 남기면 학생의 "내 기록"과 단원 페이지에 바로 보입니다. 미제출 학생만 따로 볼 수 있습니다.
- **문항별 정답률**: OX 문항마다 몇 %가 맞혔는지. 60% 미만은 빨간색으로 표시됩니다. 아래에 학생들이 고른 **헷갈린 개념** 집계가 나옵니다.
- **학생별 포트폴리오**: 학생 한 명의 단원별 개념 정리와 OX 결과(○×).

구글 시트에서는 메뉴 **[SJ 대시보드] → [요약 탭 새로 만들기]**를 누르면 학생 × 단원 표(`대시보드` 탭)가 만들어집니다.
(메뉴가 안 보이면 시트를 새로고침하세요.) `config.js`의 `SHEET_URL`에 시트 주소를 넣으면 대시보드에 "구글 시트 열기" 버튼이 생깁니다.

> 참고: OX 점수는 학생 브라우저에서 채점해 보내는 방식이라, 마음먹고 조작하는 것을 완전히 막지는 못합니다. 학습 점검용으로는 충분하지만, 성적에 크게 반영한다면 지필 평가와 함께 쓰는 것을 권합니다.

## 9. 화면 밝기

머리글의 ☀️/🌙 버튼으로 어두운 화면과 밝은 화면을 바꿀 수 있습니다(브라우저마다 기억). 밝은 화면에서 과목 색이 연하면 `config.js`의 `colorLight`로 조정하세요.

## 10. 개인정보와 공개 범위

- **구글 시트**: 선생님이 공유하지 않으면 선생님만 볼 수 있습니다. 공동 담당 선생님과 공유하면 그분은 학생 비밀번호까지 볼 수 있으니, 공유할 때는 이 점을 생각해 주세요.
- **웹 앱 주소**: "모든 사용자"로 배포해도, 그 주소로는 코드에 정해 둔 것만 돌려줍니다. 로그인 없이 받을 수 있는 것은 문제(정답 제외)와 개념 요약뿐이고, 학생 기록은 본인 출입증으로만, 반 전체 기록은 교사 계정으로만 볼 수 있습니다.
- **GitHub(공개 저장소)**: 화면 코드와 그림만 올라갑니다. 명단·비밀번호·정답·학생 기록은 올라가지 않습니다. `apps-script` 폴더는 올리지 않아도 됩니다(올려도 비밀 정보는 없습니다).
- 비밀번호는 시트에 글자 그대로 저장됩니다. 학교 계정 비밀번호처럼 다른 곳에서 쓰는 비밀번호는 쓰지 않게 안내해 주세요.
